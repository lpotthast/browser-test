# browser-test-macros

The `#[browser_test]` attribute of [`browser-test`](https://crates.io/crates/browser-test), a test runner for browser
tests written in async Rust.

Don't depend on this crate directly. Depend on `browser-test` and use the attribute through its re-export,
`browser_test::browser_test`. See the [`browser-test` README](https://github.com/lpotthast/browser-test#readme) and
the [attribute's documentation](https://docs.rs/browser-test/latest/browser_test/attr.browser_test.html).
